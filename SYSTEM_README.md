## ⚙️ What Each Phase Does

### Phase 1: Affiliate Engine (`run_unified_automation.py`)
- Fetches 7 live products per network (21 total)
- Generates LinkSynergy tracking URLs for Rboutique
- Builds clean product-card-only sites (no opt-in forms, no backend disclosure)
- Outputs: `traffic_feed.json`, 3 site HTML files, 3 Telegram messages
- Pushes to GitHub → Sites live at:
  - `https://upratapsinghshekhawat-code.github.io/rboutique-affiliate/`
  - `https://upratapsinghshekhawat-code.github.io/amazon-affiliate/`
  - `https://upratapsinghshekhawat-code.github.io/clickbank-affiliate/`

### Phase 2a: Copywriter (`copywriter.py`)
- Reads `traffic_feed.json`
- Generates sales-optimized captions using AIDA/PAS/BAB frameworks
- Assigns serial numbers (1-21) for Linktree
- Creates content pillars per account:
  - **Luxe**: Designer for Less, Style Guide, Weekly Edit, Sale Alert
  - **Smart**: 5 Under $X, Seasonal Must-Haves, Problem Solved, Best Of
- Outputs: `content_plan.json` with captions, hashtags, serials, pillars

### Phase 2b: Video Factory (`video_factory.py`)
- Renders 21 vertical MP4s (1080x1920, 30fps, H.264, <50MB)
- **Full automation**: Downloads product images → Generates B-roll → Creates slides → TTS (Edge, female: Aria/Jenny) → Background music → Subtitles → Watermark (#ad) → Renders
- 6-slide structure: Hook → Product → Benefit → Social Proof → Price → CTA
- Outputs: `content/queue/{luxe,smart}_reels/serial_XX/video.mp4` + media

### Phase 3a: Pinterest (`poster_pinterest_auto_exec.py`)
- Generates browser automation steps for 21 pins + 2 multi-pins
- Maps pillars to boards automatically
- Uses `browser_vault_fill` with saved credentials
- Orchestrator executes via `browser_exec`

### Phase 3b: YouTube (`poster_youtube_auto.py`)
- Full Data API v3 automation (no browser needed)
- Uses saved refresh tokens → access tokens → uploads Shorts
- Adds to playlists, sets tags, descriptions, thumbnails
- **Zero touch**

### Phase 3c: Instagram (`poster_instagram_auto.py`)
- Graph API + Browser hybrid
- Posts Reels + Stories
- Updates bio with serial link
- Creates highlights, pinned posts

### Phase 3d: Facebook (`poster_facebook_browser.py`)
- Browser automation (no Page tokens needed)
- Logs into Page → Creates Reel → Adds first comment with Link #XX
- Cross-posts from Instagram content

### Phase 4: Account Maintainer (`account_maintainer.py`)
- Generates profile pics (branded, account-specific)
- Updates bios with current serial link
- Creates highlight covers (Designer, Style, Sales, etc.)
- Auto-replies to comments with Linktree serial

### Phase 5: Linktree (`linktree_updater_auto.py`)
- API v2 automation
- Updates serial links daily (new at top, retains 500 history)
- Captions reference: "Link #XXX in bio"
